下载 ComicPerfect

让故事，一格格发生。ComicPerfect 是 Mac 上的漫画创作工作台：把故事想法整理成剧情，设计并调整分镜，生成漫画页面与封面，并保存每一个版本。

安装

下载后打开 DMG，把 ComicPerfect 拖进“应用程序”。安装包已签名并通过 Apple 公证，可以直接打开，不需要安装 Python、Node 或其他开发工具。

目前只提供 Apple Silicon（M 系列芯片）版本，暂未提供 Intel 版本。

开始创作

首次打开时选择一个文件夹作为创作空间，或新建一个。系列、剧情、分镜、草稿和图片都保存在这个文件夹里，不在应用内部；备份或移动整个文件夹即可带走作品。

AI 功能需要模型服务：在本机登录 Codex，或在“创作设置”里填写自己的 API Key 和兼容 API 地址。模型服务可能另行收费，下载应用不包含模型额度。没有配置 AI 时，仍然可以手动编写和调整分镜。

更新

应用不会自动更新。有新版本时回到本页下载并重新安装；创作空间里的作品不受影响。
