使用帮助与支持

ComicPerfect 是 Mac 上的漫画创作工作台，帮助你将故事想法整理成分镜，生成页面与封面，并保存作品版本。

开始创作

打开应用后，可创建单篇漫画或系列。输入想法，配置模型后生成并编辑故事和分镜，再逐页生成漫画。作品与草稿保存在本机。

配置 AI

在“创作设置”选择文字与图像服务并填写自己的 API Key 和兼容 API 地址。文字服务与图像服务可以不同，文字 API Key 不一定支持出图。第三方可能另行收费，免费下载本应用不包含模型额度。

Codex 用户可使用“创作空间 → 连接 Codex 登录…”选择已登录 Codex 的 auth.json，通常位于个人目录的隐藏 .codex 文件夹。系统文件选择器可显示隐藏文件。应用仅加密导入访问凭据；过期后重新连接。请不要将登录文件交给他人。

共享许可与停止

首次向每个 AI 服务发送时，应用会显示接收方和数据说明。拒绝后内容不会发送给该服务。要撤回许可并中断当前生成，请使用“创作空间 → 停止 AI 共享（重启应用）”。应用重启后需重新同意。

已有创作空间与导出

使用“创作空间 → 选择已有创作空间…”连接完整的原有空间。通过系统对话框授权访问；图片位于单独目录时，再选择图片文件夹。导出时通过系统保存对话框指定位置。请定期备份创作空间和图片目录。

常见问题

生成失败时，请检查服务地址、Key、模型权限、额度和网络；文字接口可用不代表支持图像模型。Codex 登录失效时重新连接。文件夹权限失效时从菜单重新选择。参考角色图片需由你自行提供并拥有适当权利，商店包不附带第三方角色参考图。

启动失败时，确认其他商店测试实例已退出，再重新打开。商店版本地界面使用 18765 端口，普通 Mac 版默认使用 18764；不要手动将两者设为同一端口。
