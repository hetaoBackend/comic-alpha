本机创作资料

故事、系列设定、分镜、草稿、作品版本与生成图片保存在你的 Mac。应用内置创作进程，处理创作空间中的相关文件。新版 Mac 客户端通过进程间管道通信，不创建网络监听端口；较早版本的内置服务仅监听本机回环地址。应用不会将创作空间自动上传到运营者服务器。

你可通过系统选择器连接已有创作空间或图片文件夹。应用保存系统授权书签以便重启后继续访问；授权失效时会提示重新选择。请仅选择你希望本应用访问的文件夹。

AI 生成会发送什么

AI 是可选的第三方服务。文字生成可能发送你输入的提示词、相关系列设定、创作原则、故事与分镜；出图与封面生成还可能发送草图、角色参考图片及之前生成的页面；复盘和创作记忆提取可能发送相关章节和人工修改。API Key 或访问令牌用于向所选服务认证。内容可能包含你主动提供的个人信息，请在发送前检查。

商店版首次向每个服务发送前会显示接收方和共享说明。许可仅在本次应用运行期间有效，更换服务需要再次许可。你可从“创作空间 → 停止 AI 共享（重启应用）”撤回本次许可；应用会停止本地服务及正在进行的连接，重启后再次发送需重新许可。撤回不能收回第三方已经接收的数据。

第三方接收方

Codex 路径使用 OpenAI 的 ChatGPT / Codex 服务；OpenAI 兼容 API 路径使用你配置的服务地址，可能是 OpenAI、DeepSeek 或其他提供方；Google 路径使用 Google Gemini。应用不为兼容 API 地址背后的运营主体提供保证，配置前请核对其身份与政策。

第三方的数据处理地区、保留时间、是否用于改进模型及删除方式依账号类型、服务设置和各提供方的政策而定。本应用不承诺第三方不会保留或训练数据。你可阅读 OpenAI 隐私政策、Google 隐私政策、DeepSeek 隐私政策及你实际使用的兼容 API 服务政策。

凭据保存

桌面版使用 macOS 钥匙串支持的加密能力保存模型 API Key。连接 Codex 时，仅从你选择的登录文件中读取访问凭据并加密保存，不导入历史对话、插件或外部服务配置。钥匙串不可用时不会退回明文保存。访问凭据过期后需要重新连接。运行中的服务必须在内存中使用凭据完成认证。

历史版本可能在浏览器存储中保存过明文 Key；升级会在成功迁移后移除应用可见的旧条目，无法保证磁盘备份或系统历史副本同时消失。

保留、删除和备份

你可在应用中管理作品和草稿，也可通过创作空间菜单打开相关文件夹进行备份与清理。删除一条草稿或清空界面缓存不一定删除磁盘上的生成图片、其他版本和备份。模型设置中的 Key 可移除；如需彻底清理，请先备份并删除本应用的数据容器、你自行关联目录中的对应文件及不再需要的备份。卸载应用不应被视为自动删除所有外部创作文件。

本机诊断日志用于排查服务启动和运行问题。我们未在本版本加入广告跟踪或运营者分析上传；Apple 可能按其设置处理商店、下载或系统诊断数据。

你的选择

你可以不配置 AI、拒绝共享、停止共享、移除 Key、取消外部目录授权或停止使用本应用。拒绝 AI 不影响本地浏览和编辑已有内容，但依赖模型的生成功能不能执行。向第三方提出访问、删除等请求时，请使用其提供的渠道。
