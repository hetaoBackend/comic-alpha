## 修复

- 系列接口将认证、额度、模型配置、网络/超时分开处理；返回可恢复的提示和稳定错误码，不把第三方响应或 Key 放入用户错误消息。保留 SDK 异常类型，避免包装后被误判成本地资料错误。
- 兼容接口分镜使用 JSON object 模式并在提示中给出 schema，仍用 Pydantic 验证输出；请求限时 120 秒、不隐式反复重试。DeepSeek 不支持原 json_schema 格式。
- 没有规则文档时允许空应用记录；有规则时继续强制完整核对。
- 新空间包含系列登记标记；旧空间仅在索引仍为原始空模板且没有正式系列时补标记，不覆盖作者自定义索引、作品、凭据或个人知识。
- 商店资产断言允许本产品自有品牌目录，继续排除未授权角色参考图与示例漫画。
